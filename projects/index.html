NutriPath

RAG-Grounded Medical Meal Planning Assistant

Built a retrieval-augmented generation pipeline over 31 cited clinical dietary rules across 6 chronic conditions, using sentence-transformer embeddings and cosine-similarity search backed by Redis. Encoded condition-specific safety logic (CKD lab/stage-gating, IBS safeguards) to prevent unsafe recommendations — achieved 72% top-1 / 90% top-3 retrieval accuracy across a 29-case evaluation harness.

Personal Project

FedUp

Real-Time Group Dining Decision App

A real-time group dining decision app solving restaurant selection two ways — AI-curated solo recommendations and live multiplayer voting rooms with instant match detection. Architected as a serverless full-stack app on Vercel using the Google Places API for search and the Claude API to curate personalized picks. Real-time multiplayer sync via Pusher (with automatic polling fallback) and Vercel KV for room state.

Claude APIGoogle Places APIPusherVercel KVServerless

Case study
Problem
Deciding where to eat as a group is slow and repetitive — there's no easy way to combine personal taste with what the whole group actually wants, in real time.
Approach
Designed the product in Figma and built it end-to-end in Next.js with Google OAuth and Postgres; built a friend-sourced recommendation engine on the Google Places API and Claude API; added real-time swipe-based group voting rooms with shareable codes via Redis and Pusher.
Outcome
A working full-stack app with synchronized multiplayer voting across devices and personalized picks that weight toward friends' saved restaurants.
